# find-dupes

Скрипт на PowerShell для поиска дубликатов файлов и **жёстких ссылок (hardlinks)** на диске. Заточен под большие медиатеки с кириллицей в путях и квадратными скобками в именах.

## Возможности

- Рекурсивный обход папки, фильтрация по размеру и маскам
- **Обнаружение активных хардлинков** (`fsutil hardlink list`) и их исключение из поиска дубликатов
- **Частичное хэширование** больших файлов (начало + середина + конец) — в разы быстрее полного MD5
- Группировка по размеру → хэшу, отдельный вывод хардлинков и обычных дубликатов
- **Экспорт скрипта очистки** (`cleanup.ps1`), который заменяет дубликаты на хардлинки с бэкапом (`.todel`)
- Безопасность: `-WhatIf`, переименование цели перед созданием хардлинка, восстановление при ошибке

## Структура

```
find-dupes/
├── find-dupes.ps1           # главный скрипт
├── config.ps1               # настройки
└── lib/
    ├── FileScanner.ps1      # сбор файлов
    ├── HardlinkDetector.ps1 # обнаружение хардлинков
    ├── HashCalculator.ps1   # частичное/полное хэширование
    ├── DuplicateFinder.ps1  # группировка дубликатов
    ├── Reporter.ps1         # вывод результатов
    └── CleanupExporter.ps1  # генерация cleanup.ps1
```

## Запуск

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\find-dupes.ps1
```

Настройки — в `config.ps1` (путь, фильтры, хэш, действие очистки).

## Очистка

Скрипт **только генерирует** `output/cleanup.ps1` и **не выполняет** его. Запуск — вручную:

```powershell
# Предпросмотр
.\output\cleanup.ps1 -WhatIf

# Реальная замена дубликатов на хардлинки
.\output\cleanup.ps1
```

## Замечания

- Хардлинки работают **только в пределах одного тома NTFS**.
- `New-Item -Target` в PowerShell интерпретирует `[ ]` как wildcard — создание хардлинков идёт через `cmd /c mklink /H`.
- `fsutil` на сетевых дисках не работает — запускать на машине, где диск подключён локально.
- Возможны единичные погрешности из-за разных Unicode-символов тире (`-` vs `–`) в именах; такие файлы обрабатываются вручную.
